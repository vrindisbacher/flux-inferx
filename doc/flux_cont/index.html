Returns the callees of a function. Unresolved trait calls fall back to the trait method DefId rather than being dropped, so default-method bodies remain reachable in the call graph.

Try to resolve a trait call to a concrete impl. Returns the resolved impl DefId when the impl overrides the method; otherwise returns the original (trait) DefId so the default method body is still reachable in the call graph.
